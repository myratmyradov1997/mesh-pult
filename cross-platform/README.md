# Пульт МЭШ для Windows и Linux

Небольшое окно, чтобы выставлять оценки, «Н» и «без д/з» в электронном журнале
МЭШ без браузера. Неофициальная утилита, с ДИТ/МЭШ не связана.

## Что умеет

- Уроки дня по времени; подряд идущие уроки одной группы — один блок
  с переключателем «отметки идут в 1-й / 2-й урок».
- Клик по уроку → список класса → кнопки **5 4 3 2 Н**.
- Уже выставленное видно сразу: оценки подсвечены (бирюзовым — на этом уроке,
  фиолетовым — на соседнем уроке двойного), отсутствующие приглушены
  с пометкой «Н ·» или «УП ·», в строке урока — «Н 2 · УП 5».
- **Ошибся — нажми ещё раз**: повторный клик по подсвеченной оценке или «Н»
  удаляет её из журнала. «↩ Отменить» удаляет последнее, что поставил пульт.
- **☑ Перекличка**: отметь отсутствующих кликом по фамилии и отправь «Н»
  всем сразу (на двойном уроке — можно на оба урока).
- «Поверх окон» — окно не прячется за браузером.
- Сам сообщает, когда на GitHub вышла новая версия.

## Установка

Скачайте файл из последнего [релиза](https://github.com/myratmyradov1997/mesh-pult/releases/latest).

### Windows

`MeshPult-Windows-Setup.exe` — установщик. Права администратора не нужны:
программа ставится в ваш профиль, появляется в меню «Пуск»; по желанию — ярлык
на рабочем столе и автозапуск при входе в Windows.

При первом запуске Windows может показать «Windows защитил ваш компьютер»
(у программы нет платной цифровой подписи). Нажмите **«Подробнее» →
«Выполнить в любом случае»**.

Без установки: `MeshPult-Windows-portable.zip` — распакуйте и запустите
`MeshPult.exe`.

### Linux

`MeshPult-Linux-x86_64.AppImage` — один файл, установка не нужна:

```bash
chmod +x MeshPult-Linux-x86_64.AppImage
./MeshPult-Linux-x86_64.AppImage
```

Собран на Debian 10, поэтому работает и на старых дистрибутивах
(Astra Linux 1.7, РЕД ОС, Альт, Ubuntu 20.04+). Если AppImage не запускается,
возьмите `MeshPult-Linux.tar.gz`, распакуйте и запустите `MeshPult/MeshPult`.

## Вход в МЭШ

1. Откройте https://school.mos.ru в браузере и войдите в «Кабинет учителя».
2. Запустите пульт — он сам возьмёт вход из cookies браузера
   (Chrome, Edge, Firefox, Chromium, Brave, Opera, Vivaldi) и номер профиля
   учителя из данных сайта.

Если пульт не смог взять вход сам (так бывает с новыми Chrome и Edge на
Windows), он покажет окно «Вход в МЭШ»: в браузере нажмите F12 → «Application»
(«Приложение») → Cookies → `https://school.mos.ru`, скопируйте значение
`aupd_refresh_token` и вставьте. Дальше пульт продлевает вход сам.

Токены хранятся только на вашем компьютере (`~/.mesh_token`,
`~/.mesh_refresh_token`, `~/.mesh_profile_id`). Ученики и оценки живут
в памяти окна и никуда не передаются, кроме самого МЭШ.

## Сборка из исходников

```bash
pip install -r cross-platform/requirements.txt pyinstaller
pyinstaller --onedir --windowed --name MeshPult \
    --add-data cross-platform/icon.png:. --paths . \
    cross-platform/mesh_pult_gui.py
dist/MeshPult/MeshPult --selftest --log selftest.log   # проверка без сети
```

Установщик Windows: `ISCC /DAppVer=1.1.0 cross-platform\installer.iss`.
Всё это делает GitHub Actions (`.github/workflows/build-cross.yml`): сборка,
самопроверка собранной программы, снимки окна, релиз по тегу `v*`.

Вся работа с API МЭШ — в `mesh_remote.py` и `mesh_automation_v3.py`
(общие с Mac-версией).
