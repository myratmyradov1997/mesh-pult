# Пульт учителя (МЭШ) — MenMeshPult

Меню-приложение для macOS, чтобы выставлять оценки, «Н» и «без д/з»
в электронном журнале МЭШ **без браузера**: панель / иконка в меню-баре,
расписание за день, списки классов, уже выставленные отметки.

**Это неофициальная утилита, не связана с ДЭПК/МЭШ. Войдите одним, читает
только ваш собственный токен из cookies вашего браузера. Не передаёт и не хранит
персональные данные учеников: ФИО и отметки живут в памяти на время сессии.**

## Что умеет

- Панель-продолжение чёлки MacBook (наведите мышь в вырез) — на MacBook
  с вырезом; на других Mac — иконка 🎓 в меню-баре (оба варианта в репо).
- Уроки дня со временем; сдвоенные уроки — блок с переключателем
  «отметки идут в 1-й / 2-й урок».
- Клик по уроку → список класса → кнопки **5 4 3 2 Н** у каждого ученика.
- Кнопки уже выставленных оценок подсвечены:
  бирюзовым — на активном уроке, фиолетовым — на соседнем уроке двойного,
  оранжевым — «Н»; отсутствующие (Н/УП, откуда бы их ни поставили) приглушены,
  в строке урока — «Н 2 · УП 5».
- Повторный клик по подсвеченной оценке или «Н» удаляет её из журнала;
  «↩︎ Отменить» удаляет последнее, что поставил пульт.
- «📋 Перекличка» — отметить отсутствующих и отправить «Н» одним пакетом.
- «Без д/з сейчас» — отметка «без домашнего задания» на текущий урок.
- **Windows и Linux** — отдельное окно-пульт с теми же функциями:
  см. [cross-platform/README.md](cross-platform/README.md) и релизы.
- Кэш чистится при смене дня; токен берётся из cookies Chrome/Helium.
- Esc / ✕ / уход мыши — панель закрывается.

## Установка (для учителя)

```bash
xcode-select --install       # если ещё не установлены
bash install.sh              # авто: чёлка → чёлка-версия, иначе меню-бар
# или принудительно: bash install.sh --menubar | --notch
```

Что произойдёт:
1. Создастся Python-окружение `~/.meshpult/venv` (requests, browser_cookie3,
   pycryptodome) — мост к API МЭШ.
2. Соберётся приложение в `~/Applications/MeshPult.app`.
3. Запишется конфиг `~/.config/mesh-remote/config.json`.
4. Ставится LaunchAgent → пульт стартует сам при входе в систему.

## Вход в МЭШ

- Откройте https://school.mos.ru в **Rosme или Chrome** и войдите
  в «Кабинет учителя». Пульт сам возьмёт токен из cookies (`aupd_token`).
- Токен живёт примерно сутки. Достаточно раз в день открыть school.mos.ru
  в Chrome — пульт обновится при следующей панели.
- Если пульт показывает «нет токена» — значит вы не залогинены: войдите заново.

## Сборка руками

```bash
bash build.sh      # swiftc обе версии: MeshPultNotch и MeshPultMenubar
```

Конфиг: `~/.config/mesh-remote/config.json` (python-путь, путь моста,
необязательно: notchWidth/panelWidth).

## Архитектура

- `main_notch.swift` — панель-«чёлка» (Swift/AppKit, без сторонних библиотек);
- `main_menubar.swift` — вариант с иконкой в меню-баре;
- `mesh_remote.py` — CLI-мост: приложение вызывает его subprocess'ом и
  получает JSON (`today`, `students`, `grades`, `status`, `act mark|absence|
  nohomework`);
- `mesh_automation_v3.py` — работа с API МЭШ: токен-цепочка (MESH_TOKEN →
  ~/.mesh_token → cookies Chrome/Helium), расписание, профили, выставление.

## Приватность

- Токен хранится в `~/.mesh_token` (chmod 600) на вашем Mac.
- ФИО учеников и отметки: только в памяти процесса, на диск не пишутся.
- В репозитории нет авторских данных; ваш config создаётся при установке.
